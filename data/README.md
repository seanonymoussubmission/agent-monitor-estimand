# Data acquisition

The four corpora are public. Download into this directory:

- **C1** `nebius/SWE-agent-trajectories` (HuggingFace) → `data/swe_agent_traj/`
- **C2** `nebius/SWE-rebench-openhands-trajectories` → `data/swe_rebench/`
- **C3** `Mosi-AI/LiveClawbench-trajectories` → `data/liveclaw/`
- **C4** Latent Programming Horizons corpus → `data/lph/`

Run-level outcome tables (`runs_laguna.csv`, `runs_qwen.csv`) are derived from C4 and
regenerated by the preprocessing step in `scripts/`. Exact version hashes are pinned in
the paper's Data Availability statement.
